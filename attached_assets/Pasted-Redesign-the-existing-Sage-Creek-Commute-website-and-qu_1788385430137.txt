Redesign the existing Sage Creek Commute website and questionnaire.

IMPORTANT:
The current version is too editorial/luxury/over-designed.
It does NOT match the intended vibe.

We are changing the design direction.

==================================================
NEW DESIGN DIRECTION
==================================================

I want the product to feel:

- simple
- modern
- calm
- premium but understated
- student-friendly
- product-focused
- mobile-first
- very clean

Think:
- classic Apple-style product simplicity
- clean onboarding UX
- restrained, neutral, minimal interface
- large whitespace
- clear hierarchy
- beautiful typography without being flashy
- elegant but not artsy
- modern app/product landing page, not a fashion/editorial site

DO NOT copy Apple directly.
But DO follow the same principles:
- minimal
- disciplined
- high readability
- clean layout
- subtle confidence
- no visual clutter

==================================================
WHAT TO REMOVE / CHANGE FROM CURRENT VERSION
==================================================

The current version has several wrong-direction choices. Fix them:

1. Remove the “luxury magazine / editorial” feel.
2. Remove overly dramatic serif-heavy layouts.
3. Remove giant artsy sections that feel like branding fluff.
4. Remove fancy conceptual copy that sounds vague.
5. Remove dark blue oversized statement blocks if they feel too brand-heavy.
6. Remove excessive visual complexity and decorative layouts.
7. Remove “concept website” energy.
8. Make it feel more like a real product people would actually use.

The site should feel closer to:
- a great onboarding flow
- a clean startup landing page
- a polished student mobility product

==================================================
TYPOGRAPHY
==================================================

Typography is extremely important.

Use a clean sans-serif system for the primary UI.
Prefer something like:
- Inter
- SF Pro style system font stack
- or another clean neutral sans-serif

For example:
font-family:
- ui-sans-serif
- system-ui
- -apple-system
- BlinkMacSystemFont
- "Inter"
- "Segoe UI"
- sans-serif

DO NOT make serif fonts the main visual identity.
If a serif is used at all, use it extremely sparingly or not at all.
Default direction: mostly sans-serif.

Headlines should be:
- large
- clean
- strong
- modern
- not ornamental
- not overly compressed
- not overly decorative

Body text should be:
- very readable
- neutral
- clean
- light enough to feel modern, dark enough to be legible

==================================================
COLOR / UI STYLE
==================================================

Keep the palette very restrained.

Use:
- warm white / off-white or very light neutral background
- dark gray / near-black text
- subtle gray borders
- one restrained accent color

Good accent options:
- muted blue
- soft navy
- slate blue
- or a clean subtle indigo

Avoid:
- loud orange
- overly saturated colors
- giant visual color blocks unless used very intentionally
- too many colors

Cards should be:
- rounded
- soft
- lightly bordered
- subtle shadow or no shadow
- calm

Buttons:
- simple
- rounded-pill or rounded-xl
- clean solid primary button
- understated secondary button

Overall feel:
- airy
- polished
- product UI
- not “designed to impress Dribbble”

==================================================

This screen is very important.

The current version is okay structurally but should be visually improved.

I want a clean schedule UI with separate weekday rows/cards.

For each weekday:
- day label
- on/off toggle
- arrival selector
- leave selector

Use 30-minute intervals throughout the practical day.

Arrival options:
6:00 AM to 10:00 PM in 30-minute increments
plus “Varies”

Leave options:
6:00 AM to 11:00 PM in 30-minute increments
plus “Varies”

Design this schedule UI to feel:
- clean
- obvious
- polished
- modern
- easy to scan
- mobile-friendly

On mobile:
stack nicely
do not cram tiny controls

If possible:
use card rows with good spacing, not an ugly HTML table feel.

Example structure per day:
[Toggle] Monday
Arrive at U of M [dropdown/select]
Leave campus [dropdown/select]

If off:
collapse the time selectors.
