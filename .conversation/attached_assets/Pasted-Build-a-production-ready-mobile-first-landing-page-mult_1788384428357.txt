Build a production-ready mobile-first landing page + multi-step commute questionnaire for a U of M student carpool concept focused ONLY on Sage Creek, Winnipeg.

IMPORTANT:
- Do not make this look like a school survey.
- Do not use words like “pilot”, “MVP”, “research study”, “startup experiment”, etc. in customer-facing copy.
- It should feel like a clean modern consumer mobility product for college students.
- Do NOT use stock photography.
- Keep the visual style very close to a polished modern startup: lots of whitespace, strong typography, rounded cards, subtle borders, restrained shadows, one tasteful accent color, excellent mobile UI.
- The experience should be one URL with multiple questionnaire screens, not separate page reloads.
- The entire site must work extremely well on iPhone/mobile first, but also look good on desktop.

TECH:
- Use React + TypeScript.
- Use Tailwind CSS.
- Use a simple backend/API.
- Store final questionnaire responses in a database.
- If Replit provides a native managed database/Postgres option, use it.
- Do NOT rely only on browser localStorage for final submissions.
- Validate all submitted data server-side.
- Store timestamp, source/UTM params if present, user role, all answers, and contact info.
- Build clean reusable components.
- Do not overengineer.

========================================
DESIGN REQUIREMENTS
========================================

The visual style is extremely important.

Use:
- clean white/light background
- dark high-contrast typography
- one subtle modern accent color
- rounded 12–24px corners
- thin neutral borders
- generous spacing
- tasteful micro-interactions
- smooth screen transitions
- excellent tap targets
- modern typography
- minimal icons/emojis where useful

Avoid:
- giant gradients
- neon colors
- cheesy car stock images
- generic startup illustrations
- huge amounts of text
- survey-looking layouts
- fake reviews
- fake numbers
- excessive animations

On mobile, each questionnaire screen should feel clean enough that one-handed use is easy.

Make radio/select cards large and tappable.

Schedule UI especially should feel polished.

The goal of this website is ONLY:
1. explain the concept,
2. collect high-quality Sage Creek U of M commuter data,
3. measure driver/rider interest,
4. validate scheduling liquidity,
5. validate rider willingness-to-pay versus driver compensation expectations,
6. collect contact information for people we may contact later.
